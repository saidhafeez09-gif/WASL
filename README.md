# Build WASL From Your Phone

### Method 1: GitHub Actions - Free
1. Create GitHub account on phone browser
2. New repo → Upload all project files
3. Add `.github/workflows/build.yml` from main README
4. Tap Commit → Actions tab → Wait 8 min → Download APK
5. Send APK on WhatsApp

### Method 2: PC Friend
1. Zip project folder → Send to friend on WhatsApp
2. Friend runs: `flutter build apk --release`
3. Friend sends APK back

### APK Size
`app-arm64-v8a-release.apk` = 20MB. Works on 90% of phones after 2018.  
`app-armeabi-v7a-release.apk` = 18MB. For old phones.

Share via WhatsApp. No internet needed after install.# WASL
Calls videos without Internet
